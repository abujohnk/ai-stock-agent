## What This Project Does

This system automatically tracks 28 AI and technology stocks across India and 
global markets, scores them on financial fundamentals, and publishes a 
professional investment report — every week, with no manual work required.

You open the live link on any day and you see a real report built from 
real data fetched that week. The writing, the analysis, the rankings — 
all generated by an AI agent pipeline, not written by hand.

## How It Works — The 4-Agent Pipeline

The system is built as a sequential pipeline. Each agent has exactly one job. 
The output of each agent becomes the input for the next.


Agent 1 Agent 2 Agent 3 Agent 4
Data Fetcher → Financial → Insight → Report
Analyst Generator Builder

stock_data → analysis → report → ai_stock
.json _results _insights _report
.json .json .html



### Agent 1 — Data Fetcher
**File:** `agent1_data_fetcher.py`

Agent 1 connects to Yahoo Finance via the `yfinance` library and fetches 
live financial data for all 28 stocks. For each stock it collects:

- Current price and 52-week high/low
- Market capitalisation
- Revenue (with year-on-year history for growth calculation)
- Net income and profit margins
- Return on equity (ROE)
- Debt-to-equity ratio
- Free cash flow

It also calculates two derived metrics that Yahoo Finance does not provide directly:
- **Revenue growth %** — calculated from the last two years of financial statements
- **3-year price CAGR** — calculated from 5 years of daily price history

Once data is collected, Agent 1 sends a sample to Claude and asks it to 
validate the data quality — checking for suspicious values, missing fields, 
and overall reliability. Claude returns a quality score out of 10.

**Output:** `stock_data.json` — raw data for all 28 stocks

---

### Agent 2 — Financial Analyst
**File:** `agent2_financial_analyst.py`

Agent 2 reads the raw data and scores every stock on five financial metrics 
using market-aware benchmarks. Indian and global stocks are judged against 
their own peer groups, not against each other — an Indian mid-cap is not 
expected to have the same margins as NVIDIA.

**The scoring model:**

| Metric | Weight | What it measures |
|--------|--------|-----------------|
| Revenue Growth % | 25% | How fast the company is growing |
| Net Margin % | 20% | How much profit it keeps from revenue |
| Return on Equity % | 20% | How efficiently it uses shareholder capital |
| 3-Year Price CAGR | 20% | How the market has rewarded it over time |
| Debt/Equity Ratio | 15% | How conservatively it is financed |

Each metric is scored 0–100 using tiered benchmarks. The five scores are 
combined into a **composite score out of 100**.

Stocks are then assigned a rating:
- **Strong Buy** — composite score 75+
- **Buy** — 60 to 74
- **Hold** — 45 to 59
- **Watch** — 35 to 44
- **Avoid** — below 35

For the top 10 stocks, Agent 2 asks Claude to write a short analyst note 
explaining what drives that stock's ranking in plain language.

**Output:** `analysis_results.json` — all 28 stocks ranked with scores, 
ratings, and analyst notes

---

### Agent 3 — Insight Generator
**File:** `agent3_insight_generator.py`

Agent 3 is where the system goes beyond what a spreadsheet can do. It reads 
the ranked data and makes six separate calls to Claude, each asking it to 
write one section of a professional investment report:

1. **Executive Summary** — the big picture across all 28 stocks
2. **India Deep Dive** — what the data says about the Indian AI/tech sector
3. **Global Deep Dive** — what drives the global AI leaders
4. **India vs Global Comparison** — a direct head-to-head on every metric
5. **Top Stock Picks** — a paragraph on each of the top 5 stocks
6. **Risk Factors** — honest assessment of the weakest names and sector risks

Claude is given the actual numbers from the analysis and told to write 
flowing prose — no bullet points, professional tone, specific references 
to company names and figures. The result reads like something a real 
equity research team would publish.

**Output:** `report_insights.json` — six sections of narrative text

---

### Agent 4 — Report Builder
**File:** `agent4_report_builder.py`

Agent 4 takes everything — the narrative from Agent 3 and the data from 
Agent 2 — and assembles it into a single self-contained HTML file. 
No server required. Anyone can open it in a browser.

The report includes:
- A header with key statistics (universe size, India avg score, Global avg score, top stock)
- A dashboard with India vs Global score comparison bars and rating distribution chart
- A top 3 podium showing the medal winners with their key metrics
- Six prose sections from Agent 3
- A full ranked table of all 28 stocks with colour-coded ratings and score bars

The entire visual design is built in dark mode with a professional financial 
data aesthetic — colour-coded green through red by rating, score bars that 
fill proportionally, market badges distinguishing Indian and global names.

**Output:** `ai_stock_report.html` — the final published report

## Automation — How It Stays Live

The pipeline runs automatically every Monday at 7am UTC using GitHub Actions.

The workflow:
1. GitHub spins up a fresh Ubuntu server
2. Installs Python 3.12 and all required libraries
3. Reads the Anthropic API key from GitHub Secrets (never stored in code)
4. Runs all 4 agents in sequence
5. Saves the new HTML report to the `docs/` folder
6. Commits and pushes the update back to the repository
7. GitHub Pages serves the updated file at the live URL

This means the report reflects real market data from within the past week, 
always, with no manual intervention.

## How to Run It Yourself

**1. Clone the repository:**
```bash
git clone https://github.com/abujohnk/ai-stock-agent.git
cd ai-stock-agent
```

**2. Install dependencies:**
```bash
pip install anthropic python-dotenv yfinance pandas
```

**3. Add your API key:**
```bash
# Create a .env file
# Add this line: ANTHROPIC_API_KEY=your-key-here
```

**4. Run the pipeline:**
```bash
python agent1_data_fetcher.py
python agent2_financial_analyst.py
python agent3_insight_generator.py
python agent4_report_builder.py
```

**5. Open the report:**
```bash
start ai_stock_report.html   # Windows
open ai_stock_report.html    # Mac
```

Get a free Anthropic API key at: https://console.anthropic.com

## What I Learned

**Agent design:** The biggest lesson was keeping each agent focused on 
exactly one job. Early on I was tempted to combine steps, but the 
single-responsibility design made debugging far easier — when something 
went wrong, I knew exactly which agent to look at.

**Prompt engineering:** Getting Claude to write in a specific professional 
tone required careful prompting. Telling it the audience, the format, 
the word limit, and what not to do (no bullet points, no generic statements) 
produced dramatically better output than a simple instruction.

**Data quality:** Yahoo Finance data is free and generally reliable, but 
it has quirks — split-adjusted prices, missing fields for smaller stocks, 
currency labelling inconsistencies. Building the scoring model to handle 
None values and market-aware benchmarks was essential.

**Automation mindset:** Building something that runs reliably without 
you watching it requires thinking about failure modes upfront. Every 
agent has error handling so one failed stock fetch doesn't crash the 
whole pipeline.
